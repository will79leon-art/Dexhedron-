## Reporting a Vulnerability
If you discover a potential security vulnerability, please do not open a public issue — instead follow one of the options below so we can handle reports privately and securely:

1. Use GitHub's security advisory flow: https://docs.github.com/en/code-security/security-advisories

2. Or contact the maintainers directly at: security@your-domain.example (replace with a working email address). Include:
   - Affected version(s)
   - A clear description of the vulnerability and steps to reproduce
   - Any proof-of-concept exploit code, if available

We aim to respond within 3 business days with an initial acknowledgement.

## Coordinated Disclosure
We ask reporters to give maintainers reasonable time to investigate and fix vulnerabilities before public disclosure. Once a fix is available we will publish a security advisory describing the issue and mitigation steps.

## Credits
If you report a security issue and would like to be credited, let us know in your report.
